# SAP-SCM-Week6-Performance-Evaluation-Continuous-Improvement
SAP SCM Week 6 internship assessment on simulated supply-chain KPI evaluation and continuous improvement. Includes a six-month performance dashboard, OTIF and forecast accuracy trends, inventory and logistics cost analysis, SAP APO/IBP monitoring guidance, root-cause analysis, validation tests, and a 30/60/90-day improvement roadmap.
