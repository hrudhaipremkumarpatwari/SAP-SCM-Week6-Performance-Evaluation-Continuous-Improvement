# Week 6 Assessment Overview — Performance Evaluation and Continuous Improvement in SAP SCM

## Assessment focus
This repository contains the Week 6 internship assessment on performance evaluation and continuous improvement in SAP SCM. The work uses a six-month simulated KPI dataset to review service, forecast, production, supplier, inventory, logistics cost, exception, utilization, waste, and data-quality performance.

## Data and visual documentation
The data/ folder contains the reproducible simulated KPI CSV. The diagrams/ folder contains the performance-monitoring flow and PDCA improvement cycle.

## Repository standard
The six-assessment series uses a consistent structure: a root README, the final assessment and supporting analysis under docs/, and editable process diagrams under diagrams/. Structured datasets are stored separately under data/ when applicable.

## Scope note
All monthly KPI values, targets, trends, and improvement effects are illustrative learning assumptions. They do not represent extracted live SAP production data or completed production testing.
